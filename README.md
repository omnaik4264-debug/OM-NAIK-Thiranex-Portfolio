# OM NAIK - Thiranex Personal Portfolio

This project is an original full-stack portfolio inspired by the structure and interactions demonstrated in the GreatStack HTML/CSS/JavaScript portfolio tutorial.

## Tech stack
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite

## Run in VS Code

1. Open this folder in VS Code.
2. Open the terminal.
3. Create a virtual environment (recommended):
   `python -m venv venv`
4. Activate it:
   Windows PowerShell:
   `venv\Scripts\Activate.ps1`
5. Install Flask:
   `pip install -r requirements.txt`
6. Start the app:
   `python app.py`
7. Open:
   `http://127.0.0.1:5000`

A file named `portfolio.db` will be created automatically after the server starts.

## Customize before submission

Edit `templates/index.html`:
- Replace the email address.
- Replace LinkedIn and GitHub links/text.
- Replace the project descriptions with your actual work.
- Add your actual photo if you want one.
- Update skills/experience/education.

## Important
The original GreatStack tutorial demonstrates a responsive HTML/CSS/JavaScript portfolio and a contact form that can send data to Google Sheets. This version is intentionally rebuilt as original code and uses Flask + SQLite for the backend/database requirement.
